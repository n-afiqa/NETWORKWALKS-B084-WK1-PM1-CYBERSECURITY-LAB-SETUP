
# Troubleshooting

## Overview

This section documents troubleshooting cases encountered while configuring and running virtual machines in VMware. Each report covers the issue, root cause, solution, and lessons learned.

## Troubleshooting Reports

| Issue | Affected System | Root Cause | Report |
|---|---|---|---|
| VMware VM Black Screen due to Misconfiguration | Kali Linux, Windows 11, Android-x86 | 3D acceleration setting, interrupted installation, or incorrect installation option | [View Report](configuration/vmw-black-screen.md) |
| Android-x86 Internet Failure Due to Routing Misconfiguration | Android-x86 | Routing rules did not correctly direct outbound traffic | [View Report](networking/android-no-internet-access.md) |
| Kali No Internet Access due to VMware NAT Gateway Conflict | Kali Linux | Conflicting ARP responses from VMware NAT gateway addresses | [View Report](networking/kali-no-internet.md) |
